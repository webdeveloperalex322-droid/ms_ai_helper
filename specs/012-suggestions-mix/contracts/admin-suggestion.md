# Contract: админское API подсказок

**Feature**: 012-suggestions-mix | Изменение существующих `GET/POST /v1/internal/assistant/suggestions` и `PATCH /v1/internal/assistant/suggestions/:id`.

## Новые поля

| Поле | Тип | Обяз. | Где | Правила |
|------|-----|-------|-----|---------|
| `screenContexts` | string[] | нет | create, patch, ответ | значения из `catalog`, `cart`, `checkout`, `empty`; пустой массив равнозначен отсутствию; неизвестное значение → `400` |
| `payload.slots.calories_max` | number \| null | нет | create, patch, ответ | положительное число либо `null` |

## Обратная совместимость

| Сценарий | Поведение |
|----------|-----------|
| Запрос без `screenContexts`, с `screenContext` | как сейчас: подсказка доступна в одном указанном контексте |
| Запрос без обоих полей | контекст `catalog` |
| Запрос с обоими полями | приоритет у `screenContexts`; `screenContext` сохраняется как есть, не перезаписывается |
| `PATCH` с `screenContexts: []` | ограничение по контекстам снимается, в силу вступает `screenContext` |

Существующие поля (`title`, `sortOrder`, `enabled`, `target`, `activeFrom`, `activeTo`, `allowedBr`, `payload`, `availabilityRules`, `fallbackPayload`) не меняются.

## Смысл полей времени

| Поле | Смысл | Не предназначено для |
|------|-------|----------------------|
| `activeFrom` / `activeTo` | абсолютное окно показа: акция до даты, сезонная подсказка | времени суток — ежедневные окна задаются настройкой системы и привязываются к `payload.slots.scenario` (ADR-015) |

Администратор не управляет окнами времени суток через подсказку: чтобы подсказка стала обеденной, ей задаётся `scenario: lunch`.

## Сервисные подсказки

| Правило | Значение |
|---------|----------|
| `payload.intent` | `info_question` |
| `payload.slots` | пустой объект; слоты подбора товаров к сервисной подсказке не применяются |
| `payload.retrieval_query` | обязателен: именно он идёт в поиск по базе знаний города как текст вопроса |
| `availabilityRules.check_products_exist` | игнорируется для `info_question`; пригодность определяется наличием проиндексированной базы знаний города |
| `fallbackPayload` | обязателен: текст на случай, когда релевантных фрагментов нет |

Создание сервисной подсказки с непустыми слотами подбора не отклоняется, но слоты игнорируются; это фиксируется в описании поля Swagger.
